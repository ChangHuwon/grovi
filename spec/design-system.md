# GROVI 디자인 시스템

본 문서는 GROVI 페이지의 시각 언어를 정의합니다. 영감은 `eluocnc.com/ko/elix` 페이지에서 가져왔으며, 카피 톤은 객관·전문 도큐먼트로 유지됩니다.

---

## 톤앤무드 — 한 줄로

> **"몰입형 다크 네이비 × 대형 타이포 × 패널형 스크롤. 시각은 임팩트, 카피는 절제."**

ELIX 페이지의 시각 임팩트(딥 네이비, 대형 타이포, 패널 전환, 슬래시 모티프)를 차용하되, 마케팅 카피톤(귀엽고 친근한 대화체)은 차용하지 않습니다.

## 패널 페이지네이션

ELIX 패턴 차용. 각 섹션을 하나의 "패널"로 다루고, 우측 또는 상단에 현재 패널 번호 표시.

### 형식

```
01 / 08
02 / 08
...
08 / 08
```

### 위치
- Desktop: 우측 고정 (`position: fixed; right: 2rem; top: 50%`)
- Mobile: 섹션 진입부 inline 표시

### 스타일

```css
.panel-counter {
  font-family: var(--font-mono);
  font-size: 0.875rem;
  font-weight: 600;
  letter-spacing: 0.1em;
}
.panel-counter .current { font-size: 1.5rem; }
.panel-counter .divider { opacity: 0.4; }
.panel-counter .total { opacity: 0.6; }
```

## 컴포넌트 패턴

### Phase Box (단계 박스)

플로우 다이어그램의 각 단계 표현. 4개 또는 3개를 가로 배치.

```
┌──────────────────┐
│  01    DISCOVER  │ ← 번호 + 이름
├──────────────────┤ ← 구분선
│ • 비즈니스 환경  │
│ • 이해관계자    │
│ • 사용자 리서치 │ ← 서브 프로세스 리스트
│ • 요구사항 정의 │
│ • KPI 수립      │
└──────────────────┘
```

- 박스 상단에 트랙 컬러 strip (높이 4px)
- 번호는 트랙 accent 컬러
- 이름은 큰 폰트, 인디고 다크
- 서브 프로세스 닷은 트랙 accent

### Stage Detail Card (4축 카드)

각 단계의 목적·활동·AI·산출물을 4축으로 정리.

```
| Stage Name (large)         |
| 목적        | ...           |
| 주요 활동   | ...           |
| AI 활용     | ...           |
| 산출물      | ...           |
```

- 좌측에 트랙 컬러 vertical strip (4px 또는 6px)
- 4축 라벨은 인디고 컬러, 본문은 진한 회색

### CTA Button

```css
.cta-button {
  display: inline-flex;

  gap: 0.5rem;
  padding: 1rem 2rem;
  background: var(--color-indigo);

  transition: transform 0.2s, background 0.2s;

.cta-button:hover {
  background: var(--color-indigo-dark);
  transform: translateY(-2px);
}
```

## 인터랙션·애니메이션

### 진입 애니메이션

스크롤 진입 시 페이드 인 + 살짝 위로 이동.

```css
.fade-in-up {
  opacity: 0;
  transform: translateY(20px);
  transition: opacity 0.8s ease-out, transform 0.8s ease-out;
}
.fade-in-up.visible {
  opacity: 1;
  transform: translateY(0);
}
```

IntersectionObserver로 viewport 진입 감지.

### Hero — 미니멀 모션

- "GROVI" 타이포 자체에 미세한 글로우 또는 stretch 애니메이션 (선택)
- 또는 정적 — ELIX의 비디오 루프 대신 GROVI에서는 정적 + 후광 효과 권장
- 영상 사용은 옵션이며, 없어도 됨

### 다이어그램 진입 모션

SVG 요소가 viewport 진입 시 단계별로 그려지는 효과 (선택):
- 노드: scale + fade
- 화살표: stroke-dasharray 애니메이션

v1에서는 정적 SVG로 시작, v2에서 모션 추가.

### Hover 인터랙션

- Phase Box: 미세한 lift (`translateY(-2px)`) + shadow 강화
- Stage Detail Card: 동일
- CTA Button: 컬러 시프트 + lift
- Stage Index 항목: 텍스트 컬러 시프트

## 반응형

### Breakpoints

```css
--bp-mobile: 375px;
--bp-tablet: 768px;
--bp-desktop: 1280px;
--bp-wide: 1440px;
```

### Track Phase Boxes 적응

- Desktop (≥1280): 4개 가로 배열 (Build·Agent), 3개 가로 (Opts)
- Tablet (768-1279): 2×2 그리드 (Build·Agent), 3개 가로 또는 세로 (Opts)
- Mobile (<768): 세로 스택, 화살표는 ↓ 방향

### Hero Typography

- Desktop: 16vw 크기
- Mobile: 22vw 크기 (한 화면 가득)

### Panel Counter

- Desktop: 우측 고정 표시
- Mobile: 각 섹션 상단 inline 표시 (고정 안 함)

## 접근성

- 모든 SVG에 `<title>`, `<desc>` 포함
- 다크 ↔ 라이트 텍스트 콘트라스트 WCAG AA 이상 (4.5:1 본문, 3:1 헤더)
- 모든 인터랙티브 요소에 `:focus-visible` 스타일
- Skip-to-content 링크
- 한국어 페이지 명시 (`<html lang="ko">`)
- 다이어그램 노드는 가능하면 button/link 처리하여 키보드 접근 가능
